避坑提醒

  • 一个应用长到尾：别每步都开新仓库，任务板一个 repo 一路演进，作品集故事才连贯。
  • 测试别拖到最后：从项目 3 起每个项目带测试，养成习惯比补测容易。
  • 部署从最省事平台起步：Railway / Render 连 GitHub 自动部署；前端 Vercel。先跑通「推送即上线」。
  • Agent 一定要带 UI：纯后端 Agent 竞争力弱，你的前端优势正好用在这里（任务板前端就是载体）。
  • Python 只学前必需的：重点放 Agent 生态，语法几天就够。
  • RAG 是可选插件不是必需：先跑通「规划 → 调工具 → 观察」循环，RAG 按场景再加。
  • MCP 是 2026 硬通货：项目 6 把任务板能力暴露成 MCP 工具，面试能讲「模型自己决定调哪个」。
